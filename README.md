# Fight Factory Manchester - Complete Digital System

Complete digital growth system built for Fight Factory Manchester.

## Contents

- `website/` - Public-facing website with booking, class timetable, lead capture, membership calculator
- `dashboard/` - Owner management dashboard with revenue tracking, CRM, automation
- `portal/` - Member portal with booking, workout tracking, achievements, AI coach

## Tech
- Pure HTML/CSS/JS - no build step required
- Fully responsive
- Self-contained (no external dependencies except Google Fonts and images)
